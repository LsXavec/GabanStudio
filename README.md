# AnimStudio

A node-graph 2D animation studio built on the traditional anime pipeline
— genga, shiage, henshū — with a GPU brush engine that imports Krita,
Photoshop and Procreate brushes.

**This repository carries releases only** (the draft/tester channel).

## Install

Download **AnimStudio-Setup.exe** from the
[latest release](../../releases/latest) and run it. Per-user install, no
admin needed. The app checks this repo's latest release and offers
"relaunch to update" when a newer build is published.

`animstudio.exe` (the bare app binary) is what the in-app updater
downloads — testers want the Setup exe.
